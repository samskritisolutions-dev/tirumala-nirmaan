# Thirumala Constructions & Developers website

A responsive Next.js 14 + React + TypeScript website using Tailwind CSS, Framer Motion and Lucide icons.

## Run locally
1. Install Node.js 18.17+.
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open http://localhost:3000

## Notes
- Brand name follows the uploaded company profile: THIRUMALA CONSTRUCTIONS & DEVELOPERS.
- Company facts and project names are based on the supplied profile.
- Project photography currently uses remote Unsplash image URLs as visual placeholders. Replace these with approved company project photographs before launch.
- The enquiry form opens the visitor's default email app with the details prefilled; it is not connected to a backend.
- Verify the office address/map pin and add verified social links before launch.
